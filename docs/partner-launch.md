# MOGG BATTLE: рейтинги и партнёры

Версия: 05.10.2026. Подписка на партнёра добровольная; базовая игра доступна без неё.

## Первый бартер

Один канал, один рекламный пост и одно задание на 7 дней. Сначала согласовать условия и дату поста. Не обещать определённое число подписчиков: аудитория приложения ещё не доказана. Не подключать несколько обязательных подписок при входе.

Обмен: партнёр публикует пост с персональной ссылкой, MOGG размещает канал в Bonus Club с внутренним бонусом. Партнёр добавляет @MoggBattleGameBot администратором своего публичного канала для проверки подписки. Не требуются права удаления сообщений или публикации постов. Сервер проверяет фактическое членство через getChatMember, включая статус restricted/is_member; ошибки Telegram не засчитываются как подписка.

Рейтинг RP меняется через рейтинговые бои. Партнёрские задания дают только Points на оформление. Один игрок получает бонус за одно задание один раз. Бонус доступен и тем, кто был подписан ранее: число полученных наград нельзя представлять как число новых подписчиков.

## Подключение после договорённости

Никакие партнёры не добавлены автоматически. Через серверный SQL-доступ создать game_campaigns и partner_campaigns. Например, заменить значения в запросе реальным названием и username, затем выполнить после проверки администраторского доступа бота:

```sql
begin;
insert into public.game_campaigns(slug,label) values ('partner_first','Название канала');
insert into public.partner_campaigns(slug,title,username,reward_points,is_active,ends_at)
values ('partner_first','Название канала','real_channel_username',100,true,now()+interval '7 days');
commit;
```

Ссылка для рекламного поста: `https://t.me/MoggBattleGameBot?startapp=c_partner_first`.

Интерфейс показывает максимум три действующих предложения. У каждого свои кнопки «Открыть канал» и «Проверить подписку». Истёкшие и отключённые предложения не дают бонус. Размер бонуса сервер берёт из базы, клиент не может его изменить.

## Проверка результата

```sql
select c.slug,c.title,
  (select count(*) from public.game_attribution a where a.campaign=c.slug) as attributed_players,
  (select count(*) from public.partner_claims r where r.campaign_id=c.id) as rewarded_checks,
  (select count(distinct e.player_id) from public.game_events e
     join public.game_attribution a on a.player_id=e.player_id and a.campaign=c.slug
     where e.name='session_open' and e.created_at>=c.starts_at+interval '1 day') as returned_after_start_day
from public.partner_campaigns c;
```

Атрибуция считает аккаунты, открывшие рекламную ссылку. Проверки показывают подтверждённое членство на момент получения бонуса, не удержание подписчиков. Последний показатель — возвращавшиеся после первого дня кампании, не когортный D1 retention. Не выдавать эти значения за просмотры поста, новых подписчиков или гарантированную выручку.

## Визуальное направление

Монохромная fashion-типографика и один лавандовый акцент. Oswald 600 для заголовков, Manrope 500/700 для интерфейса; шрифты с кириллицей хранятся локально вместе с OFL-лицензиями. Референсы: Pinterest editorial typography / black & white и Editorial explorations by Camelia Cucolea на Dribbble. Саму графику и фотографии авторов не копировали. В предпросмотре — буквенные карточки, в игре — загруженные участниками фото. Сгенерированные NPC-портреты и старые крипто-ассеты исключены.

## Проверка перед первой кампанией

Два реальных Telegram-аккаунта: подписанный и неподписанный. Проверить успешный бонус, отказ без подписки, повтор без нового начисления, выключенную кампанию и отсутствие прав администратора. Автоматические тесты покрывают интерфейс, Telegram-ответы и атомарное начисление в БД, но не заменяют этот проход в Telegram с каналом партнёра.
